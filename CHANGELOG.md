# Changelog

All notable changes to this plugin will be documented here.

## 1.0.0 — initial release

- Added the `wavemaker` Cursor Plugin manifest for marketplace submission.
- Added the `wavemaker` MCP server pointing at `https://api.wavemaker.io/mcp` (OAuth 2.1 + PKCE, no API key).
- Added a short skill that confirms before `generate_and_render` and other credit-spending calls.
- Logo: official Wavemaker mark from https://wavemaker.io/favicon.svg, on a padded white tile.
